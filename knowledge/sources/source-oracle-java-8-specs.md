# Oracle Java 8 Language Specification
Status: Official Standard (JSR 335)
Publisher: Oracle Corporation

## Abstract
Java Platform, Standard Edition 8 introduces Lambda Expressions, Default Methods, and the Stream API to enable functional-style operations on streams of elements.
