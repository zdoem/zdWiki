# Oracle Java 21 Specification (JEP 444)
Status: Official Standard (Java 21 LTS)
Publisher: Oracle Corporation

## Abstract
Introduces virtual threads to the Java Platform. Virtual threads are lightweight threads that dramatically reduce the effort of writing, maintaining, and observing high-throughput concurrent applications.
